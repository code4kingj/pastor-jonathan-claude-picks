# Pastor Jonathan Birthday Disney Picks — Build Brief

Version: v0.001
Source video: https://www.youtube.com/watch?v=Ok72hT9iOpY

## 🌱 SC's pillar

- Everyone watches the supplied Walt Disney World 2026 compilation together.
- Every ride, attraction, show, and experience appears in the same order as the video.
- Entries are colorful and visually recognizable, not a monochrome text list.
- Each person organizes a personal Top 33.
- The app combines every person's rankings into a family result showing what the group should prioritize first.
- Everyone can access the finished page.

## ➕ Hermenia injections (reverse anytime)

- A synchronized “Watch & Pick” mode with a video timestamp button on every card.
- Attraction cards categorized by park, land, and experience type.
- Drag-and-drop on larger screens plus accessible tap-to-rank, move-up, move-down, and remove controls for phones and children.
- Autosave, visible completion progress, tie handling, and a private family room code.
- Aggregate scoring uses rank points plus first-place votes, number of family wishlists, and a transparent tie-break.
- Attraction-specific imagery/color treatments with a clear unofficial-family-planner notice; no claim that the app is an official Disney product.

## Support system

- Source inventory retains timestamp and evidence confidence so uncertain transcript names can be corrected without rewriting the app.
- Mobile-first responsive layout, keyboard access, readable contrast, and reduced-motion support.
- Local demo mode must work without cloud credentials; shared-room mode is layered on top when an authorized backend/deployment is available.
- Tests cover ranking limits, reorder behavior, persistence, aggregation, ties, empty rooms, duplicate display names, and narrow screens.

## Completion boundary

Done means the app has the verified source inventory, personal Top 33 ranking, multiple-member aggregation, colorful responsive cards, persistent storage, tested build, and a verified shareable URL. A local prototype alone is not the final completion boundary.
